# Curated episode stories

Use these distinct filenames:

- **Complete canonical record:** `docs/episode-<number>.md`
- **Curated story:** `docs/stories/episode-<number>-story.md`

For example, `docs/episode-34.md` is the complete record, while
`docs/stories/episode-34-story.md` is its curated story.

Always include `-story` in a curated story's filename. A story selects from
the record; it does not replace it. Renaming a story must preserve its contents.
